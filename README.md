# Brew & Bliss Cafe Website

A modern and responsive cafe website developed using HTML, CSS, and JavaScript. The website showcases a cafe's services, menu, gallery, customer reviews, and table reservation functionality with an elegant and user-friendly design.

## Features

### Home Section

* Attractive hero banner with background image
* Welcome message and call-to-action button

### About Us

* Introduction to the cafe
* Responsive layout with image and text content

### Menu Section

* Featured coffee and dessert items
* Product cards with images and pricing
* Interactive hover effects

### Gallery

* Responsive image gallery
* Smooth image hover animations

### Customer Reviews

* Testimonial section displaying customer feedback
* Clean and professional review cards

### Table Reservation

* Reservation form for customers
* Name, phone number, date, time, and guest count inputs

### Navigation Bar

* Sticky navigation menu
* Smooth scrolling between sections

### Dark Mode

* Toggle between light and dark themes
* Enhanced user experience
